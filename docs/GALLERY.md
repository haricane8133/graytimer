Browse all 115 available watchfaces for the e-paper watch project.

The number before each name is the face's catalog number: write it to the
watch from a phone over NFC to show that face. The [catalog](CATALOG.md)
explains how.

---

Faces marked with * are procedurally generated by `watchfaceutils/generate_geometric.py` (pure 1-bit shapes, no source artwork).

```bash
cd watchfaceutils
```

- **Display**: 200x200 pixels, 1-bit monochrome
- **Format**: Percentage-based positioning (0-100%)
- **Fonts**: 66 custom fonts included
- **Layout Modes**: Single-line and two-line text layouts
- **Refresh**: Partial (fast) and full (ghosting-free) modes
